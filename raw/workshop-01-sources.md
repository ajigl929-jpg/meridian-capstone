# Workshop 01: Public Sources for the Research Wiki

## Overview
This workshop provides a fallback list of sources for ingesting into a
research wiki. The assignment requires students to ingest an initial
source provided by an instructor, find a second source independently,
and add at least one more for homework. A minimum of three public
sources must be ingested by September 20, excluding the client brief.

## Source Management Instructions
Students should save each source in a `raw/` folder with its title and
original URL, then review what the retrieval agent actually captured
before ingestion. If fetches return incomplete or error content,
students should seek assistance on Teams rather than proceeding.
